# Pel·lícules

## 1. Els orígens dels herois
- Protagonistes: Iron Man, Spider-Man i Captain America.
- Antagonista: Loki.
- Escenari: Nova York.
- Argument: Els herois descobreixen que existeixen altres persones amb habilitats extraordinàries i decideixen unir-se.
- Capítol relacionat: Capítol 1.

## 2. L'amenaça dels vilans
- Protagonistes: Els Avengers.
- Antagonista: Ultron.
- Escenari: Diferents ciutats del món.
- Argument: Una organització secreta utilitza tecnologia avançada per crear una amenaça contra els herois.
- Capítol relacionat: Capítol 2.

## 3. La batalla pel futur
- Protagonistes: Els Avengers.
- Antagonista: Thanos.
- Escenari: La Terra i l'espai.
- Argument: Els Avengers han d'unir totes les seves forces per evitar que Thanos controli les Gemmes de l'Infinit.
- Capítol relacionat: Capítol 3 i Capítol 4.

## 4. El nou univers
- Protagonistes: Els Avengers.
- Antagonista: Una nova amenaça desconeguda.
- Escenari: La Terra.
- Argument: Després de la batalla final, els herois descobreixen que una nova amenaça està començant a aparèixer.
- Capítol relacionat: Capítol 5.
